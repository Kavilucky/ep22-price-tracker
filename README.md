# Трекер цен 24/7: товары и авиабилеты без переплаты (Эпизод 22)

Исходники: [https://github.com/Kavilucky/ep22-price-tracker](https://github.com/Kavilucky/ep22-price-tracker)
```bash
git clone https://github.com/Kavilucky/ep22-price-tracker
```

Свой мониторинг динамики цен: скрипт на Python проверяет карточки круглые сутки,
притворяется мобильным Safari, держит вежливые паузы и присылает падение цены
в Telegram. Работа идёт без абонентской платы: нужен свой компьютер или сервер.

## Быстрый старт за 3 минуты

1. Поставьте Python 3.11 и Docker (Docker нужен только для режима 24/7).
2. Создайте бота у @BotFather (команда /newbot), заберите токен.
3. Узнайте свой chat_id у @userinfobot (команда /start).
4. Скопируйте `products.example.json` в `products.json`, впишите 1–3 карточки:
   название, ссылку, желаемую цену и CSS-селектор цены (как найти селектор:
   открыть карточку в браузере, F12, клик правой кнопкой по цене,
   «Проверить», скопировать селектор).
5. Проверка без Docker:
   `pip install -r requirements.txt`
   `set TELEGRAM_BOT_TOKEN=ваш_токен` и `set TELEGRAM_CHAT_ID=ваш_id` (Windows)
   `python price_tracker.py --once`
6. Режим 24/7:
   создайте файл `.env` с двумя строками (токен и id),
   `docker compose up -d`, логи: `docker compose logs -f`.

## Как это устроено

- Опрос каждой карточки не чаще раза в 5–10 минут (настройка `min_interval_s`).
- Паузы с разбросом ±15%: ровный интервал главный маркер робота для защиты.
- Ответы 403/429: пауза 60 секунд и повтор позже, не долбление.
- Алерт не чаще раза в час на товар: порог + cooldown от спама.
- История котировок в `./data/prices.db` (SQLite): переживает перезапуск.

## Честные ограничения

- Селекторы цен пример: вёрстка витрин меняется, селектор придётся обновлять.
- Капчи и личный кабинет трекер не проходит: только открытые карточки.
- Авиакомпании и маркетплейсы меняют антибот-правила: при массовых 403
  увеличьте `min_interval_s` и проверьте заголовки.
- Условия сервисов проверяйте актуальные на момент запуска.

## Резервная копия (правило 3-2-1, обязательно)

История цен это деньги: копию папки `./data` держите на внешнем диске,
вторую копию отдельно. Оригиналы не удалять, пока копия не проверена.
Разработчики Immich и авторы Kopia советуют ту же схему 3-2-1.
