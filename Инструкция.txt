ТРЕКЕР ЦЕН 24/7: ЗАПУСК ЗА 3 МИНУТЫ
Канал: @ByteAutomate_AI. Работа идёт без абонентской платы: нужен свой компьютер или сервер.

ШАГ 1. ПОДГОТОВКА (2 минуты)
1. Поставьте Python 3.11 с сайта python.org (галочка Add to PATH) и Docker Desktop.
2. Откройте Telegram, найдите @BotFather, команда /newbot, придумайте имя. Скопируйте токен вида 123456:ABC.
3. Найдите @userinfobot, команда /start, скопируйте свой id (только цифры).

ШАГ 2. КАРТОЧКИ (1 минута)
1. Распакуйте архив в отдельную папку, например C:\price-tracker.
2. Скопируйте products.example.json в products.json (копия, оригинал не трогать).
3. Откройте карточку товара в браузере, нажмите F12, кликните по цене правой кнопкой, «Проверить», скопируйте селектор.
4. Впишите в products.json: название, ссылку, желаемую цену, селектор. Начните с 1-2 карточек.

ШАГ 3. ПРОВЕРКА БЕЗ DOCKER
1. В папке откройте терминал: pip install -r requirements.txt
2. Windows: set TELEGRAM_BOT_TOKEN=ваш_токен, set TELEGRAM_CHAT_ID=ваш_id. Проверка: python price_tracker.py --once.
3. Пришла проверка цены в Telegram: всё верно. Ошибка 403/429: увеличьте min_interval_s до 900 и повторите позже.

ШАГ 4. РЕЖИМ 24/7 В DOCKER
1. Создайте рядом файл .env из двух строк: TELEGRAM_BOT_TOKEN=ваш_токен и TELEGRAM_CHAT_ID=ваш_id.
2. Команда: docker compose up -d. Логи: docker compose logs -f. Остановка: docker compose down.
3. История цен лежит в папке data (файл prices.db). Не удаляйте её.

РЕЗЕРВНАЯ КОПИЯ (правило 3-2-1, обязательно)
Скопируйте папку data на внешний диск, вторую копию держите отдельно. Оригиналы не удаляйте, пока копия не проверена. Без копии история цен и настройки пропадут вместе с диском.

ТИПИЧНЫЕ ОШИБКИ
- Токен с пробелом: скопируйте заново из @BotFather без пробелов.
- Пустой products.json: проверьте запятые и кавычки, образец в products.example.json.
- Цена не находится: поменялась вёрстка, обновите селектор через F12.
- Капча на витрине: трекер капчи не проходит, только открытые карточки.
- Алерты каждый час: так задумано (cooldown от спама), порог меняется в products.json.

ЧЕСТНЫЕ ОГРАНИЧЕНИЯ
Селекторы пример. Капчи, личные кабинеты и оплата трекер не проходит. Условия сервисов проверяйте актуальные.
